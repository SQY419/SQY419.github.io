# 容器与线性代数

## 三种容器

```text
[1,2,3]                        向量
[[1,2],[3,4]]                  矩阵
{1, {2, 3}, [4, 5]}            普通列表，可任意嵌套
```

`[ ]` 表示向量/矩阵，`{ }` 表示普通列表；两者都能嵌套。

## 向量与矩阵运算

```text
[1,2,3] + [4,5,6]              -> [5, 7, 9]
[1,2,3] * [4,5,6]              -> 32
dot([1,2,3],[4,5,6])           -> 32
cross([1,2,3],[4,5,6])         -> [-3, 6, -3]
transpose([[1,2],[3,4]])       -> [[1, 3], [2, 4]]
det([[1,2],[3,4]])             -> -2
abs([3,4])                     -> 5
length([1,2,3])                -> 3
unitV([3,4])                   -> [3/5, 4/5]
```

`*` 在两个向量之间按点积处理，结果和 `dot` 一致。

## 索引

下标从 1 开始，可以连续取：

```text
{1,2,3}[1]                     -> 1
[[1,2],[3,4]][2][1]            -> 3
```

越界会报错：

```text
[1,2,3][0]
> Error: Index out of range @ func 'index'
```

## 生成

```text
makelist(x+1, x, 0, 3)         -> {1, 2, 3, 4}
```

## 逐元素映射

容器的一元标量函数会逐元素映射：

```text
sqrt([1,4,9])                  -> [1, 2, 3]
sin([0,pi/2])                  -> [0, 1]
approx([sqrt(2),pi])           -> [1.4142135624, 3.1415926536]
```

!!! warning "还不是全部"
    容器暂不支持所有多元函数；当前重点是映射、线性代数基础与嵌套列表。
    详见 [已知限制](../limits.md)。
