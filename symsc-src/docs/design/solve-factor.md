# 求解与因式分解

## 21. solve 的分层

`solve` 采用「原生准备数据 + DSL 求解」，避免把方程文本特判写进积木：

1. **解析与分发**（`lib/api.gs`）
   - `find_top_eq` 在最外层找第一个 `=`（跳过 `==` / `<=` / `>=` / `!=`），把 `lhs=rhs` 变成残差。
   - `solve_parse_equations` 支持单方程与 `{eq1, eq2, ...}`；`split_args` 按 `()`/`[]`/`{}` 三种括号配对，所以 `{x+y=1,x-y=2}` 不会被逗号拆错。
   - `solve_parse_var_list` 支持 `x` 或 `{x,y,...}`；省略变量时用 `collect_vars_ast` 按字母序推断。
2. **原生数据层**（`lib/solve.gs`）
   - 复用 `lib/poly.gs`：`poly_from_ast` 把残差展开成稀疏多项式，再按目标变量取系数。
   - 单方程的系数 AST 交给 DSL；一次方程组把系数矩阵与右端项放进 `solve_mat` / `solve_rhs`。
   - 提供列表构造 `ctb_begin/add/end` 与 `solve_simp` 供 DSL 调用。
3. **DSL 算法**（`lang/solve.sl`）
   - 一次：`x = -b/a`。
   - 二次：首项系数为负时整体取反，`D = b²-4ac`；`D<0 → {}`，`D=0` 单根，
     否则 `(-b ± sqrt(D))/(2a)`，负号在前。
   - 一次方程组：带主元交换的高斯消元，检查矛盾行与秩，再回代。
4. **输出**：`K.List` 节点。无解 `{}`；单方程 `{r1, r2}`；方程组 `{x值, y值, ...}`。
   多组解时约定为嵌套列表，当前一次方程组只会产生 0/1 组。

## 22. factor

直接移植 `polyfactor1.sb3`，用 GoboScript 重写（`lib/factor.gs`），不经过 DSL / VM：

1. **转换**：`fac_from_ast` 复用多项式后端转成稠密一元多项式；
   `fac_content` / `fac_primitive` 拆出有理内容，得到首项为正的整系数本原多项式。
2. **表示**：`pf_coeffs` / `pf_cur` / `pf_div` 按**高次到常数**存储。
3. **提取**：先反复除以 `x`，再用有理根定理找一次因子，整数精确除法验证并更新商。
4. **Kronecker**：剩余次数 > 3 时，在 `sft..sft+d0` 上求值，选使 `Σ|f(sft+i)|`
   最小的平移，枚举因子组合，用 Lagrange / Newton 插值还原候选因子再做整数除法；
   组合上限 300000。
5. **组装**：因子写入 `pf_fcoeffs`，`factor_run` 还原 AST 并用 `mk_mul` 相乘，
   重复因子合并为幂，内容作为数值因子放最前。

范围是一元、有理系数。整数运算避免了 DSL 版本多项式除法的溢出，`x^10-1` 能完整拆分。

## 25. 因式分解求解

一元方程先走 `factor` 的因子列表，再逐个因子求解：

- 一次因子 → 线性根；
- 二次因子 → 求根公式；
- 不可约的 `a*x^n + b` → `x^n = -b/a` 的实根，奇数 n 一个、偶数 n 两个，
  用 `K.PowE` 保存 `x^(1/n)`，输出如 `2^(1/3)`、`3^(1/6)`；
- 其他高次因子 → 「solve 暂不支持该高次方程」。

结果按数值排序并去重（`(x-1)^2` 只给 `{1}`）。

## 31. lsolve

`lsolve([[a11, ..., b1], ...])` 接受**增广矩阵**，最后一列是右端项：

- 唯一解 → `{x1, x2, ...}`；无解 → `{}`；无穷多解 → 报错。

`lib/lsolve.gs` 用行主元高斯-约当消元、主元归一化、回代；任意行数/变量数，
系数是符号表达式时走同一套 `mk_*` / `solve_simp`。
