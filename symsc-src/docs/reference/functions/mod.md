# mod / %

```text
mod(a, b)
a % b
```

取余。`%` 的优先级与 `*`、`/` 相同。

## 示例

```text
10%3            -> 1
mod(10,3)       -> 1
10%3+1          -> 2
mod(2^64+1,3)   -> 2
mod(-10,3)      -> 2
{4%3, 5%3}      -> {1, 2}
```

## 行为细节

- 走 `nt_dec` / `nt_mod` / `nt_node`，任意精度整数都能直接取模。
- 负数按**非负余数**处理：`mod(-10,3) = 2`。
- 符号化简：`x%x`、`(x+1)%(x+1)` 直接为 `0`；被除数为 0 也返回 `0`。
- `mod(0,0)`、`0%0` 报「模数为零」。
- 非整数参数报 `mod 需要整数参数`。
