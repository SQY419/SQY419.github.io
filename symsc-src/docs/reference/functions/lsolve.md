# lsolve

```text
lsolve([[a11, a12, ..., b1], [a21, ..., b2], ...])
```

解线性方程组。参数是**增广矩阵**，最后一列是右端项，返回解列表。

## 示例

```text
lsolve([[1, 1, 3], [1, -1, 1]])
> {2, 1}
```

## 输出

| 情况 | 返回 |
| --- | --- |
| 唯一解 | `{x1, x2, ...}` |
| 无解（矛盾行） | `{}` |
| 无穷多解 | 报错 |

## 行为细节

- 行主元高斯-约当消元，主元归一化后回代。
- 支持任意行数 / 变量数。
- 系数可以是符号表达式，内部走同一套 `mk_*` 与 `solve_simp`。
