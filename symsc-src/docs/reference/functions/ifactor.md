# ifactor

```text
ifactor(n)
```

整数分解，返回升序的素数幂乘积。

## 示例

```text
ifactor(360)
> 2^3*3^2*5

ifactor(0)
> 0

ifactor(2^64+1)
```

`2^64+1` 会先做 30 万以内的小因子试除，找到 `274177`，再递归分解余下的 `67280421310721`。

## 行为细节

- 小素数试除 + Pollard-Rho 递归分解。
- 试除按 7 位分块、30 轮步进（跳过 2/3/5 的倍数）计算余数，能处理 15 位以上的数。
- **20 位以上或找不到小因子**时返回明确错误，而不是进入极慢的 Big Pollard-Rho。
- `ifactor(0)` 直接返回 `0`。
