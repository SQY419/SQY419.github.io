# factor

```text
factor(expr)
```

一元有理系数多项式因式分解。算法移植自 `polyfactor1.sb3`，用 GoboScript 重写，
不走 DSL / VM。

## 示例

```text
factor(x^2 - 1)
factor(x^3 - 1)
factor(x^10 - 1)
```

## 算法

1. **归一化**：AST → 稠密一元多项式，拆出有理内容，得到首项为正的整系数本原多项式。
2. **提取**：反复除以 `x`（常数项为 0 时），再用有理根定理找一次因子，
   每次用整数精确除法验证并更新商。
3. **Kronecker**：剩余次数 > 3 时，在若干平移点上求值，选使
   `Σ|f(sft+i)|` 最小的平移，枚举各点值的因子组合，用 Lagrange / Newton
   插值还原候选因子，再做整数除法。组合总数上限 300000。
4. **组装**：因子以整系数列表保存，最后还原成 AST 并用 `mk_mul` 相乘；
   重复因子自动合并成幂，数值内容放在最前。

## 范围与限制

- 只支持一元、有理系数；其他变量或非多项式报错。
- 系数用整数运算，避免 DSL 版本多项式除法的溢出问题，`x^10-1` 能完整拆分。
- 大规模不可约多项式会受 Kronecker 组合上限约束。
