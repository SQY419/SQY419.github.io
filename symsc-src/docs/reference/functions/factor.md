# factor

```text
factor(expr)
```

多项式因式分解。

## 示例

```text
factor(x^2 - 1)
factor(x^3 - 1)
factor(x^10 - 1)
factor(x^98 +98x^4 + 1)
```

## 算法

1. **归一化**：稠密一元多项式，拆出有理内容，得到首项为正的整系数本原多项式。
2. **提取**：常数项为0时，反复除以 `x`，再用有理根定理找一次因子，每次用整数精确除法验证并更新商。
3. **Kronecker**：剩余次数 > 3 时，在若干平移点上求值，选使
   $\sum |f(sft+i)|$ 最小的平移，枚举各点值的因子组合，用 Lagrange / Newton插值还原候选因子，再做整数除法。组合总数上限 300000。

## 范围与限制

- 只支持一元、有理系数；其他变量或非多项式报错。
- 系数用整数运算。
- 大规模不可约多项式会受 Kronecker 组合上限约束。
