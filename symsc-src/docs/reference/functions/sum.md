# sum

```text
sum(expr, var, a, b)     区间求和
sum(container)           容器求和
```

## 示例

```text
sum(x,x,0,10)
> 55

sum({1,5,9})
> 15

sum(1/x^2, x, 1, 25)
> 23485971550561141649/14626411683380640000

sum(1/x^2,x,1,20)*6
> 17299975731542641/1806412533045120

sqrt(sum(1/x^2,x,1,20)*6)
> sqrt(31250892982835045031326856961920)/1806412533045120

approx(sqrt(sum(1/x^2,x,1,20)*6))
> 3.0946695241
```

## 行为细节

- 区间上下界必须是整数；**暂不支持符号求和**。
- 有理性项用大整数分子/分母累加，结果继续参与普通加减乘除，不触发 double 溢出。
- 容器形式支持嵌套列表，会递归相加。
- 容器里的一元标量函数逐元素映射规则同样适用，见 [容器](../../guide/containers.md)。
