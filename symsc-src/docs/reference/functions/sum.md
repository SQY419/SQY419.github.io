# sum

```text
sum(expr, var, a, b)     区间求和
sum(container)           容器求和
```

## 示例

```text
sum(x,x,0,10)
> 55

sum({1,5,9})
> 15

sum(x^2, x, 1, 100000)

sum(1/x^2, x, 1, 25)
> 23485971550561141649/14626411683380640000

sum(2^x, x, 0, n)

sum(x*2^x, x, 0, n)
> -(n+1)*2^(n+1)+n*2^(n+2)+2
```

有理数求和用**分母 LCM** 合并，避免分母乘积膨胀；约分放到最后。

## 行为细节

- 支持**符号闭式**，通项是多项式时用 Faulhaber / Bernoulli 公式，`sum(x^2,x,1,100000)` 不会逐项算。数值上下界走原生大整数路径。
- 支持**几何级数**，$c*r^x$ 项用 $\frac{c(r^{e+1}-r^b)}{r-1}$；$P(x) r^x, \deg P \leq 2$有显式公式。
- 区间上下界必须是整数或纯符号。
- 数值上下界会按大小交换，确保大的在后面。
- 负上下界目前退回普通数值循环，超过 10000 项报范围过大。
- 容器形式支持嵌套列表，逐层相加。
