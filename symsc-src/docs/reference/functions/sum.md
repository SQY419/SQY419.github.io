# sum

```text
sum(expr, var, a, b)     区间求和
sum(container)           容器求和
```

## 示例

```text
sum(x,x,0,10)
> 55

sum({1,5,9})
> 15

sum(x^2, x, 1, 100000)

sum(1/x^2, x, 1, 25)
> 23485971550561141649/14626411683380640000

sum(2^x, x, 0, n)

sum(x*2^x, x, 0, n)
> -(n+1)2^(n+1)+n*2^(n+2)+2
```

## 三条加速路径

1. **符号闭式**：通项是多项式时用 Faulhaber / Bernoulli 公式，
   `sum(x^2,x,1,100000)` 不再逐项算。数值上下界走原生大整数路径，
   `100000^6` 这类中间量不会溢出。
2. **几何级数**：`c*r^x` 项用 `c*(r^(e+1)-r^b)/(r-1)`；
   `P(x)*r^x`（`deg P ≤ 2`）有显式公式。
3. **快速求值**：有理函数通项直接按整数 `k` 精确求值，跳过 `subst` / 规则化简；
   `sum(x, x, b, e)` 走等差数列 `(b+e)(e-b+1)/2`，O(1)。

有理数求和用**分母 LCM** 合并，避免分母乘积膨胀；约分放到最后。

## 行为细节

- 区间上下界必须是整数（或纯符号）；非多项式通项在符号上下界下报
  「符号求和只支持多项式」。
- 数值上下界会按大小交换，保持「10 到 0 也求和 1..10」的语义。
- 负上下界目前退回普通数值循环，超过 10000 项报范围过大。
- 容器形式支持嵌套列表，逐层相加。
