# approx

```text
approx(expr)
```

把精确结果转成浮点近似。
利用 Scratch 特性实现了大浮点数表示，类似`1.14514e1919810`，不局限于`1e308`。

## 示例

```text
approx(2^(2^100))
> 1e381600854690000000000000000000

approx([sqrt(2),pi])
> [1.4142135624, 3.1415926536]

approx(sqrt(sum(1/x^2,x,1,20)*6))
> 3.0946695241
```

## 行为细节

- `2^(2^100)` 等大数会以科学计数法输出，而不是变成 `Infinity`。
- 容器会逐元素近似，见 [容器与线性代数](../../guide/containers.md)。
