# solve

```text
solve(equation, var)
solve({eq1, eq2, ...}, {x, y, ...})
```

解方程 / 方程组。方程写成 `lhs=rhs`（会在最外层找第一个 `=`，跳过 `==`、`<=`、`>=`、`!=`），
内部转成 `lhs - rhs` 的残差再解。

## 示例

```text
solve(x^2 - 5*x + 6 = 0, x)
solve({x+y=1, x-y=2}, {x, y})
solve(x^3 - 1 = 0, x)
```

方程组可以省略变量列表，此时按字母序自动推断未知数。

## 输出约定

| 情况 | 返回 |
| --- | --- |
| 无解 | `{}` |
| 单方程 | `{r1, r2}`（平铺） |
| 方程组唯一解 | `{x值, y值, ...}` |
| 多组解 | 嵌套列表，每个子列表按变量顺序（格式已支持，当前一次方程组只会产生 0/1 组） |

## 会走哪些算法

1. **先因式分解**（一元方程）：一次因子给线性根；二次因子用求根公式；
   `a*x^n + b` 型不可约因子解 `x^n = -b/a`（奇数 n 一个实根，偶数 n 两个），
   根写成 `K.PowE`，例如 `2^(1/3)`、`3^(1/6)`。
2. **否则用多项式系数**：一次方程 `x = -b/a`；二次方程用判别式
   `D = b^2-4ac`，`D<0` 返回 `{}`，`D=0` 单根，否则 `(-b ± sqrt(D))/(2a)`。
3. **一次方程组**：带主元交换的高斯消元，行阶梯形后检查矛盾行；
   秩小于未知数个数时报「有无穷多解」，否则回代。

结果会按数值排序并去掉重复根，例如 `(x-1)^2` 只输出 `{1}`。

## 错误

| 情况 | 提示 |
| --- | --- |
| 非多项式 | `solve 只支持多项式方程` |
| 次数 > 2 且不可因式分解 | `solve 只支持一次和二次方程` / `solve 暂不支持该高次方程` |
| 非线性方程组 | `solve 方程组暂只支持一次方程组` |
| 恒等式 / 欠定 | `有无穷多解` |
