# solve

```text
solve(equation, var)
solve({eq1, eq2, ...}, {x, y, ...})
```

解方程（组）。方程写成 `lhs=rhs`（会在最外层找第一个 `=`，跳过 `==`、`<=`、`>=`、`!=`），
内部转成 `lhs - rhs == 0` 再解。还不支持解不等式。

## 示例

```text
solve(x^2 - 5*x + 6 = 0, x)
solve({x+y=1, x-y=2}, {x, y})
solve(x^3 - 1 = 0, x)
```

方程组可以省略变量列表，此时按字母序自动推断未知数。

## 输出约定

| 情况 | 返回 |
| --- | --- |
| 无解 | `{}` |
| 单方程 | `{r1, r2, ...}` |
| 方程组唯一解 | `{x, y, ...}` |
| 多组解 | 嵌套列表，每个子列表按变量顺序 |

## 错误

| 情况 | 提示 |
| --- | --- |
| 次数 > 2 且不可因式分解 | `solve 只支持一次和二次方程` / `solve 暂不支持该高次方程` |
| 非线性方程组 | `solve 方程组暂只支持一次方程组` |
| 恒等式 / 欠定 | `有无穷多解` |
