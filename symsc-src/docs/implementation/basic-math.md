# 基础数学

对应函数：`sqrt`、`sin/cos/tan`、`exp/ln/log`、`mod/%`。

## 平方根

分子、分母分别提取最大平方因子，得到 $\sqrt{n/d} = \frac{k}{m} \sqrt{\frac{n/k^2}{d/m^2}}$，剩余根式为 1 时直接返回有理数。数字超过 `MAX_SQRT = 1000000` 跳过化简。

## 三角函数

`sin`、`cos`、`tan` 的算法通过 DSL 和原生层实现，特殊角直接给出值。

## 指数与对数

- `exp`、`ln`、`log` 基于 DSL 与原生层，特殊参数直接给出值。模式匹配也有相关规则。例如：
```
exp(ln(x))
> x
```

## 取模

- `mod` / `%` 为整数运算是取余数，支持负数。
- 在解析和打印环节有特殊处理，保证结果一致。

## 其他

- `csc`/`sec`/`cot` 在解析时重写为 `1/sin`、`1/cos`、`cos/sin`。
