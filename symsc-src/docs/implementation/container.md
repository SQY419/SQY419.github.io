# 容器

对应函数：`length`、`makelist`、`dot`、`cross`、`transpose`、`det`、`unitV`、`abs`。

容器类函数操作列表（`K.List`），列表在 Scratch 以内部链表实现，索引从 1 开始。

## 基本操作

- `length`：返回列表节点数，直接从节点字段读取。
- `makelist`：创建新列表，参数展开成列表元素。
- `abs`：对列表中每个元素取绝对值，或计算向量模长（`K.DOT` + `sqrt`）。
- `dot`：点积，对应元素相乘再求和。
- `cross`：叉积，返回新向量（仅在三维有效）。
- `transpose`：矩阵转置，交换行列索引。
- `det`：行列式，用拉普拉斯展开或高斯消元计算。
- `unitV`：归一化向量，返回单位向量。

这些函数大多直接映射到内部列表操作或数学运算，没有特殊优化。
