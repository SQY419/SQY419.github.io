# 坐标系

## 平面坐标系

- 按住网格拖动平移；滚轮缩放（**以鼠标为中心**）；右下角按钮以软件像素原点为中心缩放。
- 显函数、隐函数采用**区块加载**：未加载的区域在拖动时不会被绘制，停下后再算、再画。
- v4.7 以后缩放会延时计算，避免卡顿。
- 4.10 支持「延时刷新」开关：关闭后在拖动过程中按固定间隔计算新区域，但可能很卡，默认开启。

## 3D 坐标系

支持二元显函数、3D 方程/不等式、3D 参数方程。

- z 轴固定，x、y 轴可以转动。
- 拖动 3D 网格时网格会高亮，表示正在平移 x-y 平面。
- 滚轮缩放的中心是鼠标所指的 x-y 平面上的点。

## 范围与分辨率

| 版本 | 像素坐标系 |
| --- | --- |
| v4.8 以下 | x = -240..240，y = -180..180 |
| v4.8 以上 | 自适应调整分辨率，见「设置 → 显示缓存」 |

参数方程与极坐标的 t / θ 范围在设置里改（`pqmin` / `pqmax` / `polmin` / `polmax`）。
