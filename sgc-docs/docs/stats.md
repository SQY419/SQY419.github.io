# 统计

SGC 支持 16 组双变量统计，默认 3 列。

## 统计表

模式区选「表格」。表格可以拖动；某列右侧出现「+」时可以新建一列。

## 输入

点单元格直接输入，当前单元格高亮；有错误会显示红色警告图标。

## 显示

输入后坐标系里出现数据点，颜色与列左侧小圆片一致。
**只有 x、y 都有值的点才会显示**——任一为空，这个点就不画。

## 列操作

点列旁的「⋯」：

- **统计**：进入列统计；
- **导入**：以空格分隔粘贴数据，如 `1 2 3 4 5`；
- **清除列数据**；
- **回归**：只在 y 列出现；
- **样式**：改颜色。

## 列统计

给出 $\sum x$、$\sum x^2$、$\bar{x}$、方差、标准差、Min、Max、Mid（中位数）。
空列表等异常会给出提示。

## 列回归

对 y 列与 x 列做回归，显示回归系数和可决系数 $R^2$。模型可选：

| 模型 | 形式 |
| --- | --- |
| 线性（默认） | $y = ax + b$ |
| 二次 | $y = ax^2 + bx + c$ |
| 指数 | $y = ae^{bx}$ |
| 对数 | $y = a + b\ln x$ |

下方「绘制」按钮会把回归曲线画进坐标系。
