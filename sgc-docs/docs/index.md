## 这是什么

SGC 始于 2022，在 Scratch 3 以及支持 Scratch 3 的平台上运行。它可以绘制显函数、隐函数、
参数方程、极坐标，做简单的统计与回归，创建几何对象，用 SGC Script 写演示动画，
用 STeX 渲染公式。

!!! tip "速度"
    在 TurboWarp / HTML 环境下，运行速度与 Desmos、GeoGebra 接近；
    参数与精度都可以自己调，能画得比 Desmos 更好。
