# 2 输入

## 2.1 输入方式

三种都行：虚拟键盘、真正的键盘、从外部导入表达式。

输入默认用 CMU Serif 系字体并带语法高亮：**函数黄色、常量绿色、运算符蓝色、文本灰色**，
其余黑色。自定义函数斜体，系统函数正体。高亮可在设置里关闭。

## 2.2 输入类型

每行左侧有「+」，点开可以选「表达式」或「纯文本」。纯文本可当注释，不参与计算，
语法错误会被忽略。

## 2.3 输入语法

SGC 会自动做错误检查（括号匹配、二元运算符、缺失对象等）。有错时左侧「+」变成红色警告符。
中文符号无法解析，但中文可以作为变量名。

可以自动转换的写法：

| 输入 | 解释 | 转义 |
| --- | --- | --- |
| `2sin(2x)` | 常量 × 函数 / 变量 | `2·sin(2·x)` |
| `xx` | 变量 × 变量 | `x·x` |
| `axsin(x)` | 变量 × 函数 | `a·x·sin(x)` |
| `xsinx` | 省略括号的函数 | `x·sin(x)` |
| `(x+1)(x-5)` | 省略乘号 | `(x+1)·(x-5)` |
| `2<x<5` | 单内容不等式 | `(2<x)and(x<5)` |

不能转换的情况：

1. `2<(x+1)<5`：中间包含两个及以上内容；
2. `sinsinx`：两个不带括号的函数；
3. 把 `sin(x)^2` 写成 `sin^2(x)`。

`pi` 可以代替 `π`。遇到多义写法（如 `asinh`）会优先匹配最长的函数名，
所以想写 `a·sin(x)` 不要写成 `asin(x)`（那是 arcsin）。

## 2.4 创建对象

### 表达式计算

直接输入 `1+1`，按 enter 得到 `2`。

### 变量

```text
a=0
a
```

输入 `a` 会自动创建未定义变量并给一个滑动条（可播放变量）。
若变量值只是一个实数就带滑动条，否则是常量：`a=sqrt(2)` 是常量；
想要常量 `a=1`，写 `a=1+0`。

变量表达式里不能出现 `x`、`y`、`z`（这种请用函数定义）；变量名不能以数字开头，
但可以包含 xyz，例如 `x1=0`、`y_2=0` 合法，`1g`、`69lyc` 非法
（`69lyc=43` 会被解析成 `69l·y·c=43`，是隐函数）。

### 函数

一元显函数直接写表达式即可，`y=` 不是必须的：

```text
1+x
y=1+x
f(x)=1+x
```

第三种写法之后可以调用。x 关于 y 的函数同理：`x=1+y`、`1+y`、`f(y)=1+y`。

3D 显函数在 3D 模式下输入同时含 x、y 的式子，例如 `xx-yy` 就是 $z=x^2-y^2$。

### 定义函数

```text
f1(u,v)=u-vsinu
myfunc(x,y)=xsiny
1+myfunc(x,x-1)
```

未定义函数黑色，已定义函数黄色斜体。想定义含系统函数名的自定义函数（如 `mysin`），
名字里至少要有一个下划线：`my_sin(x)` 合法。

函数也能以文本为参数：

```text
concat(a,b)=a & b
concat("hello ", "SGC!")
> "hello SGC!"
```

### 隐函数、不等式

隐函数必须在**最外层**有隐式符号：

```text
sin(xx+yy)=0        ✔ 隐函数
sin(xx+yy)          ✘ 被当成二元显函数 z=sin(xx+yy)
(sin(xx+yy)=0)      ✘ 被当成布尔表达式
```

含 `z` 就是三维隐函数（不等式）。SGC 不支持 `1<x<2` 这种写法，可用 `if(1<x,x)<2` 代替。

!!! warning "marching squares 的局限"
    SGC 用 marching squares，像 `(x-y)(x+y)^2=0`、`(x-1)^2=0` 这种包含切面的隐函数
    可能画不准。

### 参数方程、极坐标

```text
x=cost,y=sint       二维参数方程，变量是 t
x=cost,y=sint,z=t   三维参数方程
r=asin(cos(θ))      极坐标
r:2                 强制极坐标 r=2
```

`t` 的范围、极坐标的 θ 范围都在设置里改。
