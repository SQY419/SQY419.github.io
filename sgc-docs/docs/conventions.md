# 约定与反馈

## 书写约定

1. `Infinity` 必须大写，小写的 `infinity` 不是它。
2. 计算中 `true=1`，`false=0`。
3. 常数 `Pi`、`EulerGamma` 可以不大写；但 `Gamma` 指 Gamma 函数，不是 EulerGamma。
4. 标准颜色代码是 `aabbccdd`：`aa` 颜色、`bb` 饱和度、`cc` 亮度、`dd` 透明度，
   每段范围 00–99。例如 `00999900` 相当于 `#ff0000`。
5. v4.8 以下的像素坐标系范围是 x = -240..240、y = -180..180；v4.8 以上自适应分辨率，
   可在「设置 → 显示缓存」查看当前分辨率。
6. `NaN` 显示为 `?`。
7. `≤`、`≥` 要用 `<=`、`>=` 代替。
