# 几何

模式区选「几何」进入几何页面。拖动或滚轮移动页面，点一个工具后右侧会给出提示，
按提示完成操作。点「绘图」会把几何内容显示回输入区；直线的解析式以 `g:` 开头显示。

## 工具一览

| 中文 | English | 说明 |
| --- | --- | --- |
| 点(名称,x,y) | `point` | 在 (x,y) 建点 |
| 对象点(名称,对象[,因子]) | `objpoint` | 在对象上建点，因子决定位置 |
| 交点(对象1,对象2,名称1,名称2) | `inter` | 求交点，多余的用 `?` 占位 |
| 直线/射线/线段(名称,点1,点2) | `line` / `ray` / `segment` | 过两点的线 |
| 圆(名称,圆心,圆外一点) | `circle` | 由两点确定圆 |
| 圆规(名称,圆心,点1,点2) | `compass` | 半径 = 点1 到点2 的距离 |
| 距离(变量,点1,点2) | `distance` | 测距并赋值 |
| 角度(变量,点1,点2,点3) | `angle` | 测角并赋值 |
| 中点(名称,点1,点2) | `midpoint` | 中点 |
| 中垂线(名称,点1,点2) | `perpbisector` | 垂直平分线 |
| 垂线(名称,直线,点) | `perpline` | 过点作垂线 |
| 平行线(名称,直线,点) | `paraline` | 过点作平行线 |
| 旋转(中心,对象,名称,角) | `rotate` | 旋转 |
| 对称(轴,对象,名称) | `reflect` | 轴对称 |
| 是否垂直(直线1,直线2) | `isperp` | 判断 |
| 是否平行(直线1,直线2) | `isparallel` | 判断 |
| 多边形(poly,点1,…,点n) | `polygon_g` | 几何多边形 |
| 面积(变量,对象) | `area` | 多边形或圆的面积 |
| 角平分线(名称,点1,点2,点3[,n]) | `anglebisector` | n 等分，默认 2 |

!!! note "对象点"
    `objpoint(A,sinx)` 建的点**可以拖动**；`point(A,t,sint)` 建的点不能拖。
    `objpoint(A,siny)` 建的是 `x=siny` 上的点。`objpoint` 不能填第三个参数，
    需要时请用 `point`。

## 创建对象

选工具后，非目标类型的对象会变灰，方便你挑对象。

## 轨迹

在表达式末尾加 `loc` 即可显示轨迹，例如 `交点(l0,l2,G),loc`。

## 样式与标签

样式面板里可以改颜色，并把线型切成实线 / 虚线。
4.10 以上还能改标签：标签为空时显示点名，否则显示标签内容；标签支持[高级文本](text.md)。
