# 脚本概览

SGC Script 是 SGC 内置的脚本语言（已更新到 SGC Script II），用来做三件普通函数做不到的事：

1. **操作 SGC 底层**：添加/删除输入、改颜色、移动和缩放坐标系；
2. **画东西**：点、线、矩形、圆、文字、图片，画在独立的脚本图层上；
3. **做动画**：逐帧播放、放声音、按时间刷新画面。

它是一门命令式语言：有变量、分支、循环、函数，也支持递归。

## 进入编辑器

菜单 → **高级功能** → **脚本**。编辑器用 JetBrains Mono，带连字，当前行高亮。

| 按钮 | 作用 |
| --- | --- |
| ▶ | 运行脚本 |
| ■ | 强行停止 |
| ← | 返回编辑器 |
| 清空 | 清空当前脚本 |
| 打开 / 保存 | 读写脚本文件 |

运行中按「强行停止」是唯一能中断 `while true` 的办法。

## 第一个脚本

```text
// 在坐标系里画一条抛物线
clean();
refresh(false);

a = -3;
while a <= 3 {
    x = a;
    y = x * x;
    point(x, y, "red");
    a = a + 0.05;
}

refresh();
```

- `clean()` 清掉上一次的画；
- `refresh(false)` 关闭自动刷新，避免每个点都重绘一次（很慢）；
- 循环结束后 `refresh()` 一次性刷新。

## 语言速览

```text
// 注释
a = 1;                  // 变量
b = "text";             // 字符串
c = [1, 2, [3, 4]];     // 列表
d = true;               // 布尔

if a > 0 {
    print("positive");
} else {
    print("not positive");
}

i = 0;
while i < 5 {
    print(i);
    i++;
}

define square(x) {
    return x * x;
}
print(square(3));       // 9
```

!!! tip "和输入区的区别"
    输入区里写的是**表达式**，由计算引擎求值；脚本里写的是**语句**，按顺序执行，
    可以改界面、画图、循环。脚本不能直接“变成一个函数”给输入区调用。
