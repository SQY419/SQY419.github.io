# 3 输入对象操作

## 3.1 主界面操作

输入一个非常量、非变量对象后，左侧会出现彩色圆形，点它可显示 / 隐藏该对象。
常量和变量对象没有圆形，左侧是空的（`1+1` 没有，`x` 有）。

## 3.2 小窗口操作

每行最右侧有「⋯」按钮，点开是 More 菜单，不同类型的对象菜单不同：

- **重复输入**：把该对象复制到当前光标前。
- **重复输出**：把它计算出的结果复制到光标前（如把 `1+1` 的输出 `2` 粘进去）。
- **导出**（v4.8.7+）：弹出窗口，可「导出当前表达式」或「导出 TeX 表达式」。
- **颜色**：打开样式面板，调颜色、饱和度、亮度、透明度（0–100），可预览。
- **删除**：删除该对象。

v4.8.7 以下版本的「导出」是导出到列表，三击列表项复制。

### 导出 TeX

`1/x+1` 导出后就是 LaTeX。但如果表达式本身带 LaTeX 标记，会原样返回。
注意大型运算符（sum / int / diff）导出的是 `\mathrm{diff}(x^{x},x,x)` 这种字面形式，
不是 $\frac{\mathrm{d}}{\mathrm{d}x}x^x$ 的排版——这是语法差异，不是 bug。
