# 多边形、逐帧动画与批注

## 多边形

```text
polygon((x1,y1),(x2,y2),...,(xn,yn))
```

若首尾点相同，视为闭合轮廓并填充颜色；点的坐标可以包含表达式。

`polygon_p` 只接受点坐标（不能含表达式），但解析快很多。
注意 `polygon_g` 是几何对象，和这里的 `polygon` 不是一回事。

```text
polygon((0,0),(1,1),(2,0))             空心三角形
polygon((0,0),(1,1),(2,0),(0,0))       实心三角形
```

## 逐帧动画

只有 `polygon`、`polygon_p` 支持动画：在表达式后加 `#n` 表示第 n 帧显示。

```text
polygon((0,0),(1,1),(2,0),(0,0))#1
```

打开动画控制台（菜单 → 高级功能 → 动画）：

- 播放 / 暂停；
- 「帧：***」设置当前帧，右侧数值设置最大帧数（最大 99999）；
- 设置 → 绘图 → 动画可改速度，默认 1。

## 批注

4.8 以上版本，点右下角批注图标进入。批注会在输入区添加以 `stroke` 开头的内容。
把鼠标移到坐标系右侧可展开调色板，改颜色和笔粗；样式面板里也能改。
