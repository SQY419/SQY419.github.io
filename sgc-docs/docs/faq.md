# 常见问题

### 为什么画不了图像？

1. **没有按 enter**。SGC 没有预览，输入后必须按 `enter` 或虚拟键盘上的箭头才会解析、绘制。
2. 表达式计算量大，解析需要时间；隐函数精度设得太高也会很慢。
3. 撞上 bug 了。

### 为什么隐函数丢失细节？

精度不足。设置 → 绘图 → 当前模式里调「隐式精度」。推荐的日常值是 240–360；
1440 基本能比 Desmos 清楚，但会明显变慢。精度很高时不要在绘制过程中做别的操作，
拖动网格可能会中断正在进行的计算。

### 怎么限制定义域？

用 `if`：

```text
if(0<x<15, -x+23)
```

不要写成 `y=-x+23(0<x<15)`——那等价于 `y = -x + (23(0<x<15))`，条件只作用在 23 上。

### 为什么 $\dfrac{x^{x+1}}{(x+1)^x}$ 在 x 大时画不出来？

$\lim_{x\to\infty}\frac{x^{x+1}}{(x+1)^x}=\frac{1}{e}$，但中间的 $x^{x+1}$、$(x+1)^x$
在计算时溢出了，变成 $\infty/\infty$。类似的还有 $y=3^x\sin x$、$y=\ln x^x$。

### 为什么 $y=\ln(\sin x+\cos y)$ 在 $y<0$ 的渐近线画不出来？

因为 $\ln x$ 在 0 附近由 `NaN` 过渡到 $-\infty$。关闭设置里的「跳过未定义值」即可。

### 能导入 Arch / Alpha Math 的文件吗？

不能。函数语法不同，目前 SGC 只能导入自己的存档。

### 中文能当变量吗？

能。中文符号（比如 `≤` `≥` `π`）无法解析，但中文本身可以作为变量名。
