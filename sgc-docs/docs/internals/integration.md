# 数值积分

## 为什么要比梯形法更好

矩形法、梯形法、Simpson 法都是**等距**取点，被积函数复杂时收敛很慢。
`int(...)` 要在一个 500ms 的执行预算里给出结果，所以 SGC 用高斯型积分。

## 高斯积分

$$
\int_{-1}^{1}f(x)\,dx\approx\sum_{j=0}^{n}w_j f(x_j)
$$

节点 $x_j$ 不是等距的，而是 $n$ 阶勒让德多项式 $P_n(x)$ 的根；权重 $w_j$ 由

$$w_i=\frac{2}{(1-x_i^2)\,[P_n'(x_i)]^2}$$

给出。$n$ 个节点可以精确积分 $2n-1$ 次多项式，比等距公式高得多。

区间不是 $[-1,1]$ 时做一次线性变换：

$$\int_a^b f(x)\,dx=\frac{b-a}{2}\int_{-1}^{1}f\!\left(\frac{b-a}{2}t+\frac{a+b}{2}\right)dt$$

例：用 2 阶高斯公式算 $\int_{-1}^{1}x^2dx$，节点是 $\pm\frac{\sqrt3}{3}$、权重都是 1，
两次求值就得到精确值 $\frac{2}{3}$。

## Gauss–Kronrod

固定阶数不够用：$\int_{-1}^{1}\sqrt{|x|}\,dx$ 用 500 个节点也未必够。
解决办法是自适应——把区间二分，误差大的地方继续分。

问题是：怎么估计误差？直接算更高阶要重新算所有节点，太浪费。
**Kronrod** 在原有高斯节点的基础上补一组新节点，形成 $2n+1$ 阶公式，
两组结果之差就是误差估计：

$$\int_{-1}^{1}f\approx\sum_{j=0}^{n}w_jf(x_j)+\sum_{j=0}^{n+1}v_jf(u_j)$$

复用已有函数值，所以误差估计几乎是“免费”的。

## 自适应流程

1. 在当前区间算 Gauss 与 Kronrod 两个值；
2. 差值小于容差就接受；
3. 否则二分，对两个子区间递归做同样的事；
4. 递归到设定的深度上限就停（防止死循环）。

SGC 允许在设置里调整递归上限：被积函数波动大、结果量级大时，适当调高。

## 敛散判断

数值积分最大的坑是把发散积分算出一个有限值。SGC 的做法是观察误差序列：
如果连续多次误差都很大、且不随区间缩小而下降，就判定为发散，直接报错。

也可以在设置里关掉这个判断——有时它会把收敛很慢的正常积分误判为发散。

## 早期版本

SGC v3 用固定的 300 节点高斯积分做概率计算，没有自适应；
v4 换成 Gauss–Kronrod，精度和速度都更好。
