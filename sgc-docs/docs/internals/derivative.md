# 数值导数

## 三种差分

导数定义是

$$f'(x)=\lim_{\Delta x\to0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$$

把极限换成固定的小步长，就得到：

| 方法 | 公式 | 误差 |
| --- | --- | --- |
| 前向差分 | $\dfrac{f(x+\Delta x)-f(x)}{\Delta x}$ | $O(\Delta x)$ |
| 后向差分 | $\dfrac{f(x)-f(x-\Delta x)}{\Delta x}$ | $O(\Delta x)$ |
| 中心差分 | $\dfrac{f(x+\Delta x)-f(x-\Delta x)}{2\Delta x}$ | $O(\Delta x^2)$ |

SGC 用**中心差分**，`diff(expr, x, x0)` 算的就是它，固定 $\Delta x=10^{-5}$。

## Δx 不能太小

看起来 $\Delta x$ 越小越接近极限，实际上不是：

- $\Delta x$ 太小，$f(x+\Delta x)$ 与 $f(x-\Delta x)$ 在双精度下几乎相等，
  两者相减会把有效位全丢掉（灾难性抵消）；
- $\Delta x$ 太大，截断误差又占主导。

以 $\sin x$ 在 $x=1$ 处求导（真实值 $0.5403023058681398$）为例：

| $\Delta x$ | 计算结果 |
| --- | --- |
| $5\times10^{-4}$ | 0.5403022833555537 |
| $10^{-4}$ | 0.5403023049677103 |
| $5\times10^{-5}$ | 0.5403023056438361 |
| $10^{-5}$ | 0.5403023058569989 |
| $5\times10^{-6}$ | 0.5403023058736522 |
| $2.5\times10^{-6}$ | 0.5403023058514478 |
| $10^{-6}$ | 0.5403023058958567 |
| $5\times10^{-7}$ | 0.5403023058958567 |
| $10^{-7}$ | 0.5403023056738121 |

精度先升后降，$10^{-6}$ 之后反而变差。工程上取 $10^{-6}$ 到 $10^{-5}$ 之间最稳，
SGC 选 $10^{-5}$。

## 二阶导数

最直接的做法是对一阶导数再差分一次，但一阶导数本身有误差，再差分会把误差放大。
更好的做法是利用泰勒展开消去一阶项：

$$f''(x)\approx\frac{f(x+\Delta x)-2f(x)+f(x-\Delta x)}{\Delta x^2}$$

这个式子不依赖 $f'(x)$，精度更好，实现也简单。

## 用在哪里

- `diff(...)` 命令；
- `fSolve` 的牛顿迭代需要导数；
- 自适应作图用 $|f'(x)|$ 估计变化率（见[作图](plotting.md)）；
- 断点判断里用相邻点的差商判断跳变。
