# 内部实现概览

SGC 是**数值**计算软件，不是 CAS：它不会替你化简表达式，也不会给出精确的符号答案，
而是用浮点运算把结果算出来、把图画出来。

这一章讲它是怎么算的——不涉及 Scratch 积木怎么写，只讲算法选择和取舍。
知道这些，你在遇到「画不出来」「精度不够」「收敛太慢」时，才知道该调哪里。

## 一句话取舍

SGC 的每个算法都在**精度**、**速度**、**可实现的复杂度**之间取平衡：

- 需要 15 位精度的地方（三角函数、Gamma）用迭代或级数补足；
- 需要实时性的地方（作图、隐函数）用采样 + 插值，宁可牺牲一点精度；
- 算不动的地方（发散积分、无解方程）宁可报错或停下，也不静默给个错答案。

这也解释了很多“看起来是 bug”的行为：断点判断偶尔误判、隐函数切面画不出来、
精度调太高会卡死——都是取舍的结果，不是实现失误。
