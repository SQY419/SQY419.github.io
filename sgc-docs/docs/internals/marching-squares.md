# Marching Squares

> 这一节是补充内容：原说明书只在输入章节提了一句“SGC 使用 marching squares”，
> 没有解释它是什么。这里补上原理，以及它为什么会画不准某些隐函数。

## 为什么隐函数不能直接描点

显函数可以写成 $y=f(x)$，给定 $x$ 算 $y$ 就行。隐函数 $F(x,y)=0$ 不行——
它是一条**等值线**，同一个 $x$ 可能对应多个 $y$，甚至一段竖线。

所以要在平面上“找”出满足 $F(x,y)=0$ 的点，再连起来。Marching Squares 就是最常用的做法。

## 算法

### 1. 铺网格

把视口切成小方格。每个格子的四个角（左上、右上、右下、左下）都算一次 $F$ 的值，
只关心它的**符号**（正 / 负 / 零），不关心大小。

### 2. 每个格子看四个角的符号

四个角各有正负两种状态，共 $2^4=16$ 种组合。去掉整体取反后重复的情况，
实际只有这几种几何形态：

| 角点情况 | 线段数 | 说明 |
| --- | --- | --- |
| 4 个同号 | 0 | 曲线不经过这个格子 |
| 1 个异号 | 1 | 曲线切掉一个角 |
| 2 个相邻角异号 | 1 | 曲线横穿格子 |
| 2 个对角异号 | 2 | **有歧义**，见下 |
| 3 个异号 | 1 | 曲线切掉三个角（等价于 1 个异号，只是方向相反） |

### 3. 在边上插值

曲线穿过一条边时，用两端点的值做线性插值，求交点位置：

$$t=\frac{F(a)}{F(a)-F(b)},\qquad P=a+t\,(b-a)$$

因为只用了符号和一次插值，所以一格只需要 4 次函数求值，非常快。

### 4. 连成折线

把相邻格子里的线段按端点拼起来，就得到整条曲线。实际实现通常用哈希表按边索引
缓存交点，避免重复计算、也方便拼接。

## 歧义：鞍点

两个对角异号时，曲线有两种连法：把两个正角连起来，或者把两个负角连起来。
只看四个角是分不出来的，这叫**鞍点歧义**。

常见解法：

- 再算一次格子中心的值，按中心的符号决定连法；
- 用更精确的**渐近判别**（asymptotic decider），比较四个角值的乘积。

如果不处理，鞍点附近会出现“该连的没连、不该连的连了”的小瑕疵。
SGC 的精度设置会直接影响这类区域的观感——格子越细，歧义格越少。

## SGC 里的具体参数

「设置 → 绘图 → 隐式精度」就是网格密度：

| 项 | 含义 |
| --- | --- |
| 默认 80 | 横向 80 个单位 × 纵向 $80\times0.75=60$ 个单位，共 4800 个采样点 |
| 区块 120×120 | 计算按区块进行，所以精度必须是 4 的倍数 |
| 推荐 240–360 | 日常使用的平衡点 |
| 1440 | 细节足以超过 Desmos，但很慢 |

由于是**区块加载**，拖动时只算新进入视口的格子，已算过的直接复用；
这也是为什么隐函数在拖动时会出现“空白条带”，停下后才补上。

## 什么时候会画不出来

Marching Squares 依赖**符号变化**。如果零集两侧不换号，它就找不到曲线：

- $(x-1)^2=0$：左边是 $(x-1)^2\ge0$，除 $x=1$ 这条线外处处为正。
  只有采样点**恰好**落在 $x=1$ 上才能得到 0，概率几乎为零，所以整条直线消失。
- $(x-y)(x+y)^2=0$：$(x+y)^2\ge0$ 不换号，所以 $x+y=0$ 那一支也画不出来，
  只剩 $x=y$。

这类“切触型”零集（曲线只是碰到 0 而不穿过）是 marching squares 的固有弱点，
不是 SGC 的实现问题。数学上可以改用等值线追踪、符号距离场或更高阶的插值来改善，
但代价都不小。

## 和显函数的对比

| | 显函数 | 隐函数 |
| --- | --- | --- |
| 采样 | 沿 x 轴一维采样 | 平面上二维采样 |
| 成本 | $O(n)$ | $O(n^2)$ |
| 断点 | 四点法判断 | 天然按格子分割，不需要额外判断 |
| 弱点 | 高频振荡 | 切触型零集、鞍点歧义 |

理解了这一点，再看「隐式精度」这个设置就明白了：它不是一个“清晰度”滑块，
而是**网格密度**，直接决定能分辨多细的结构。
