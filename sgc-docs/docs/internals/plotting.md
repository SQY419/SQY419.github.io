# 作图与断点判断

## 描点法

画 $y=f(x)$ 最基本的方法：在屏幕宽度上取一串 $x$，算出 $f(x)$，把相邻点连成折线。

SGC 的「函数精度」就是这件事的密度：默认 480，表示在 480 个单位里按步长 1 采样。
调高到 4800，点更密、曲线更顺，但计算量也翻十倍。

精度是**按屏幕像素**算的，所以缩放会改变实际采样密度；这也是为什么放大后曲线
有时会短暂变粗糙，停下拖动后会重新计算。

## 变化剧烈时：自适应步长

$\sin(e^x)$ 这类函数在 $x$ 大时震荡极快，均匀采样必然失真。改进办法是按导数调步长：

1. 先算 $f'(x_i)$（可以用相邻两点的差商近似，省一次函数求值）；
2. 令下一步步长为 $1/|f'(x_i)|$；
3. 但必须给步长设上下限，否则平坦区域会一步跳到天边，陡峭区域会算到天荒地老。

这就是**自适应绘图**。它能明显改善 $y=\sin(e^x)$ 这类图像，但也会在
$y=e^x$ 这种“单调但导数一直变大”的函数上浪费算力——导数大不等于需要更密的点。

## 断点判断

只描点会把 $\tan x$ 在 $\frac{\pi}{2}$ 两侧连成一条竖线，看起来像连续函数。
要断开，就得判断“这里是不是间断点”。

### 朴素做法与它的毛病

1. 比较 $f(x_{i-1})$ 与 $f(x_{i+1})$，差超过阈值就断开；
2. 改用 $f(x_i\pm\Delta x)$；
3. 比较 $|f(x_{i-1})-f(x_i)|$ 与阈值（SGC v1、v2 用这个）。

问题很明显：$f(x)=114514x$ 在任何尺度下相邻点差都很大，会全被判定为断点。

### 四点法

SGC v4 取相邻的四个采样点，从左到右记为 $v_1,v_2,v_3,v_4$：

1. 四个点里有未定义值 → 断点；
2. **无穷间断**（如 $\tan x$、$1/x$）：两侧符号相同、中间符号相反，即
   $(v_2-v_3)(v_1-v_2)\le0$ 或 $(v_2-v_3)(v_3-v_4)\le0$，
   并且中间那一段比两侧加起来还长：
   $|v_1-v_2|+|v_3-v_4|+\varepsilon<|v_2-v_3|$；
3. **跳跃间断**（如分段函数）：两侧差商同号，但乘积很小：
   $|(v_1-v_2)(v_3-v_4)|<\varepsilon|v_2-v_3|$。

$\varepsilon$ 与缩放相关：无穷间断用 $0.01/$当前缩放，跳跃间断用 $0.015/$当前缩放。
缩放越大，$\varepsilon$ 越小，判断越严格。

极坐标与参数方程的断点判断同理，只是把 $x$ 换成参数 $t$、把 $y$ 换成对应的坐标。

## 为什么有时候会误判

四点法是启发式的：

- 变化极快的连续函数（高频振荡）会被误判成断点；
- 真实的跳跃如果幅度很小，会被当成连续；
- 在断点附近，采样点恰好落在间断点上的概率极低，所以判断永远依赖邻点的差。

设置里的「断点判断」开关就是给这种情况准备的：关掉之后，曲线会全部连起来，
适合画那些被误判的函数。
