# 方程求根

## 牛顿法

要求 $f(x)=0$，在 $x_0$ 处做泰勒展开取线性部分：

$$0\approx f(x_0)+f'(x_0)(x-x_0)$$

解出新的近似：

$$x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$$

导数用[中心差分](derivative.md)算，不需要符号求导。

### 收敛有多快

解 $x^2-x-1=0$（黄金比例），从 $x_0=1$ 出发：

| 步 | 值 |
| --- | --- |
| $x_1$ | 2.0000000 |
| $x_2$ | 1.6666667 |
| $x_3$ | 1.6190476 |
| $x_4$ | 1.6180344 |
| $x_5$ | 1.6180339 |
| $x_6$ | 1.6180339 |

五步就到 7 位有效数字。这是牛顿法的典型表现：靠近根时误差平方级下降。

### 它的毛病

- 初值不好会发散或震荡（在导数接近 0 的地方尤其明显）；
- 只找到**一个**根，找哪个取决于初值；
- 需要导数，函数不平滑时不可靠。

`fSolve(expr, x, 初值)` 的第三个参数就是让你挑根的。

## 割线法

用两点差商代替导数，省掉一次求导：

$$x_{n+1}=x_n-\frac{f(x_n)(x_n-x_{n-1})}{f(x_n)-f(x_{n-1})}$$

收敛阶约 1.618（比牛顿慢一点），但每次只要算一次函数值。

## 复合法

不需要导数的另一种迭代：

$$x_{n+1}=x_n-\frac{f(x_n)^2}{f(f(x_n)+x_n)-f(x_n)}$$

同样解 $x^2-x-1=0$，从 $x_0=2$ 出发，6 步也能到 1.6180339。
但它对初值比牛顿法更敏感——从 $x_0=1$ 出发会得到未定义结果。

## SGC 的选择

`fSolve` 用牛顿法，因为它在 Scratch 里最好实现：只需要一个差分求导，
循环体短，迭代次数少。

实际使用时的建议：

1. 初值尽量靠近你想要的根；
2. 如果返回 `NaN`，换个初值；
3. 求交点时先把两条曲线联立成一个函数，再用初值挑分支。
