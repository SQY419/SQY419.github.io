    help¶

    help()          总览
help(func)      单个函数的签名与说明

    示例¶

    help()

help(simplify)

help(series)

    行为细节¶

    • help() 列出所有命令；help(函数名) 只显示该函数的签名和说明。
    • 输出进入终端，可用拖动滚动查看历史（最多 5000 行）。
    • 快捷键 h 等价于查看帮助，c 清屏。
