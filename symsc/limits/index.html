    已知限制¶

    数学能力¶

    • det 目前只支持 1×1 / 2×2 / 3×3。
    • 完整 Gruntz mrv（exp / log 混合的极限）尚未实现。
    • sum / prod 的区间上下界必须是整数，不支持符号求和。
    • 容器暂不支持所有多元函数；当前重点是映射、线性代数基础与嵌套列表。

    规模¶

    项 上限
    节点数 MAX_NODES，超出报错
    指数绝对值 MAX_EXP
    输出长度 MAX_OUTPUT，超出截断
    数字根式化简 超过 MAX_SQRT = 1,000,000 跳过
    多元 GCD 网格 256 个采样点

    环境¶

    • 原生 Scratch 每次 warp 线程最多 500ms；大计算建议用 TurboWarp。
    • 终端最多保留 5000 行历史。
    • 只有线性文本输出，没有数学排版。

    设计上的取舍¶

    这些不是 bug，是取舍：

    • 不自动做分配律，展开要显式 expand。
    • 数值溢出时报错，不静默降级成 float。
    • 极限在有限点用洛必达/级数，无穷远用 leading-term 比较，不追求全覆盖。
