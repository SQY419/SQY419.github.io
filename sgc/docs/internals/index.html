    关于内部实现的一些说明¶

    SGC 是数值计算软件，这一章解释它怎么算。

    Scratch 的数据类型¶

    Scratch 用双精度浮点数。\(2^{100}+1-2^{100}\) 在双精度下会得到 0 而不是 1： \(2^{100}\) 是 1.2676506002282294e+30，加 1 时个位早就丢了，减法自然消掉。 双精度最小能表示到 \(10^{-320}\) 量级。

    提升三角函数精度¶

    Scratch 的 sin / cos / tan 精度只有 10 位，但 asin / acos / atan 有 15 位。 两种补救办法：

    1. 面向 + 移动：角色移到 (0,0)，面向 \(90°-u\)，前进 1 步——坐标就是 \(\cos u\)、\(\sin u\)。
    2. 牛顿迭代：令 \(f(t)=\arcsin t-x\)，初值用 Scratch 的 sin，迭代 \(y_{n+1}=y_n-\dfrac{\sqrt{1-y_n^2}(\arcsin y_n-x)}{1}\)（即 \(y_n-\dfrac{f(y_n)}{f'(y_n)}\)）， 实测最多一次迭代就到 15 位。\(\cos x=1-2\sin^2\frac{x}{2}\)。

    数值一阶导数¶

    前向、后向差分都是 \(O(h)\) 量级，SGC 用中心差分：

    \[f'(x)\approx\frac{f(x+\Delta x)-f(x-\Delta x)}{2\Delta x}\]

    \(\Delta x\) 不是越小越好：太小会让两个函数值在双精度下几乎相等，反而失效。 实测 \(\Delta x\) 在 \(10^{-6}\) 到 \(10^{-5}\) 之间最好（SGC 取 \(10^{-5}\)）。

    二阶导数用

    \[f''(x)\approx\frac{f(x+\Delta x)-2f(x)+f(x-\Delta x)}{\Delta x^2}\]

    这样不依赖一阶导数的计算，误差不会叠加。

    作函数的图像¶

    基本做法是描点：取一串 x，算 \(f(x)\)，连成平滑曲线。点越多越准，但变化剧烈的函数 （如 \(\sin(e^x)\)）仍然画不好。

    改进办法是自适应绘图：用导数估计变化率，令下一步步长为 \(1/|f'(x)|\)， 并限制最大 / 最小值。SGC v5 采用这种方法。

    数值断点判断¶

    描点法会把 \(\tan x\) 在 \(\frac{\pi}{2}\) 两侧连起来，看起来像连续函数。判断间断点的几种做法：

    1. 比较 \(f(x_{i-1})\) 与 \(f(x_{i+1})\)，差超过 \(\varepsilon\) 就断开；
    2. 改用 \(f(x_i\pm\Delta x)\)；
    3. 比较 \(|f(x_{i-1})-f(x_i)|\) 与 \(\varepsilon\)（SGC v1、v2 用这个）。

    前三种都不够通用（\(f(x)=114514x\) 会全断）。SGC v4 用四点法：取相邻四个点 \(v_1..v_4\)，

    • 有未定义值 → 断点；
    • 无穷间断：\((v_2-v_3)(v_1-v_2)\le 0\) 或 \((v_2-v_3)(v_3-v_4)\le 0\)， 且 \(|v_1-v_2|+|v_3-v_4|+\varepsilon<|v_2-v_3|\)，\(\varepsilon=0.01/\)当前缩放；
    • 跳跃间断：\(|(v_1-v_2)(v_3-v_4)|<\varepsilon|v_2-v_3|\)，\(\varepsilon=0.015/\)当前缩放。

    极坐标、参数方程同理。

    数值积分¶

    SGC 用 Gauss–Kronrod 自适应积分：

    • 高斯积分取非均匀节点，\(n\) 阶可达 \(2n+1\) 次代数精度；
    • Kronrod 在原有节点上加点，用两次结果之差估计误差；
    • 误差超限就把区间二分，递归处理（要设递归上限）；
    • 收敛判断：连续多次误差都很大时认为积分发散。

    早期版本（v3）固定用 300 节点高斯积分做概率计算。

    一元方程数值解与 fSolve¶

    牛顿迭代：

    \[x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\]

    解 \(x^2-x-1=0\) 从 \(x_0=1\) 出发，6 步就到 1.6180339。导数用 13.3 的方法算。 SGC v4 的 fSolve 就是它。

    牛顿法会震荡；割线法用两点差商代替导数；复合法 \(x_{n+1}=x_n-\frac{f(x_n)^2}{f(f(x_n)+x_n)-f(x_n)}\) 不需要导数，但对初值敏感。

    特殊函数的数值计算¶

    FresnelS / FresnelC¶

    \[S(x)=\int_0^x\sin\frac{\pi}{2}t^2\,dt,\qquad C(x)=\int_0^x\cos\frac{\pi}{2}t^2\,dt\]

    小 \(x\) 用 20 阶 Gauss 积分或级数；\(x>4.59\)（约 \(1.46\pi\)）改用渐近展开 \(S(x)\sim\frac{1}{2}-\frac{1}{\pi x}\cos\frac{\pi x^2}{2}\)，再用 Horner 形式加速。

    LambertW¶

    \(f(x)=xe^x\) 的主分支反函数，定义在 \([-1/e,\infty)\)。牛顿迭代 \(a_{n+1}=a_n-\frac{a_ne^{a_n}-x}{a_ne^{a_n}+e^{a_n}}\)，初值取 \(a_0=1\) 时 \(W(100)\) 收敛很慢；改用 \(a_0=\sqrt[3]{x/2+0.95}\) 可以快很多， \(x\gg200\) 时改用对数迭代。

    Gamma / Psi¶

    用 Lanczos 近似（\(g=7\)，\(n=9\) 系数组），\(x!=\Gamma(x+1)\)。 \(x\) 越大精度越低；\(x>25\) 时可以换 luschnyCF4，或递推 \(x!=x(x-1)!\)。 由余元公式只需算 \(x>0.5\) 的部分。\(\psi(x)=\frac{\Gamma'(x)}{\Gamma(x)}\)，同样只需算 \(x>0.5\)。

    Zeta¶

    \(\zeta(s)=\sum k^{-s}\) 在 \(s\) 接近 1 时收敛极慢（\(\zeta(2)\) 要上亿项）。 用 \(\zeta(s)=\frac{1}{1-2^{1-s}}\sum\frac{(-1)^{k-1}}{k^s}\) 和函数方程 \(\zeta(s)=2^s\pi^{s-1}\sin\frac{\pi s}{2}\Gamma(1-s)\zeta(1-s)\) 可以覆盖整个实数轴。 \(s=1\) 是极点，但 \(1/\zeta(x)\) 可以消除，SGC 对它做 20 阶 Chebyshev 近似。
